# SkupkaPCBot

Первая рабочая версия Telegram-бота для проекта мониторинга выгодных объявлений компьютерной техники в Улан-Удэ.

## Запуск

Переменная окружения:

BOT_TOKEN=токен_от_BotFather

Установка:

pip install -r requirements.txt

Запуск:

python bot.py

## Следующий этап

Подключить модуль мониторинга источников объявлений и фильтрации по:
- цене;
- модели;
- ориентировочной цене перепродажи;
- ожидаемой прибыли;
- ликвидности;
- расстоянию/городу;
- ключевым словам.

Важно: автоматический сбор данных с Avito должен учитывать доступные способы доступа и правила сервиса. Если прямой автоматический доступ ограничен, модуль нужно строить через разрешённый источник/интеграцию или другой легальный способ получения данных.
